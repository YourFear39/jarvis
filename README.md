# Jarvis — голосовой AI-ассистент для управления ПК

Персональный ассистент для Windows: понимает голос и текст, открывает программы и файлы,
ищет в интернете, ведёт заметки и задачи, управляет системой через PowerShell и реестр.

**Стек:** Python, Gemini / Claude / Groq / Cerebras / Ollama, faster-whisper (распознавание речи),
ElevenLabs + edge-tts (синтез речи с DSP-обработкой), ChromaDB, SQLite, Rich, CustomTkinter.

## Как устроено

- **Трёхуровневая маршрутизация запросов** (`core/router.py`, `core/local_handler.py`):
  1. локальные команды без LLM — открыть программу/папку, буфер обмена, громкость и т. п.;
  2. веб-поиск — DuckDuckGo, ответ собирает Groq;
  3. LLM с вызовом инструментов (tool calling), несколько вызовов за один ответ.
- **Несколько провайдеров LLM** (`llm/`) с общим интерфейсом, ротацией ключей Gemini и повторами при 429/503.
- **Безопасность** (`core/safety.py`): команды PowerShell, операции с файлами и реестром делятся
  на уровни SAFE / CONFIRM / FORBIDDEN. Опасные действия требуют подтверждения — в том числе голосом.
  Перед записью в реестр делается бэкап через `reg export`, критичные ветки заблокированы.
- **Память**: семантическая (ChromaDB) + заметки, задачи и планы (SQLite).
- **Обучение программам**: если программа не найдена, Jarvis спрашивает путь и запоминает его.
- **Игровой режим** (`core/scenarios.py`): закрывает фоновые программы (кроме белого списка) и апдейтеры, запускает Steam, Rust и Discord.
- **Голос**: push-to-talk, локальное распознавание faster-whisper, озвучка ElevenLabs с фолбэком на edge-tts.
- **Тесты**: `_test_deep.py` (126 сценариев), `_test_search.py` (качество поиска).

## Запуск

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env      # вписать ключи (достаточно GEMINI_API_KEYS)
python main.py              # текстовый режим
python main.py --voice      # голосовой режим
python main.py --gui        # окно
```

Команды в чате: `/exit`, `/clear`, `/memory`, `/help`.

## Структура

```
core/    — оркестратор, роутер, локальные команды, безопасность, память
llm/     — провайдеры LLM
tools/   — инструменты: поиск, заметки, файлы, реестр, управление ПК
voice/   — распознавание и синтез речи
ui/      — терминальный и оконный интерфейс
data/    — локальные данные (не в git)
```
