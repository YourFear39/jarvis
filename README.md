# Джарвис — Персональный ИИ-ассистент

Голосовой ИИ-ассистент с поддержкой множества провайдеров (Gemini, Claude, Ollama),
долговременной памятью и встроенными инструментами.

## Быстрый старт

### 1. Создай виртуальное окружение

```bash
cd C:\Projects\Jarvis
python -m venv venv
venv\Scripts\activate
```

### 2. Установи зависимости

```bash
pip install -r requirements.txt
```

> Первая установка может занять несколько минут — ChromaDB и sentence-transformers довольно большие.

### 3. Настрой API-ключ

Открой файл `.env` и вставь свой ключ Gemini:

```env
LLM_PROVIDER=gemini
GEMINI_API_KEY=твой_ключ_здесь
```

### 4. Запусти Джарвиса

```bash
python main.py
```

## Команды в чате

| Команда | Что делает |
|---------|-----------|
| `/exit` | Выход |
| `/clear` | Очистить экран |
| `/memory` | Статистика долговременной памяти |
| `/help` | Справка |

## Смена провайдера

Изменить в `.env`:
```env
LLM_PROVIDER=claude    # или gemini, ollama
```

## Структура проекта

```
core/       — оркестратор, память, личность
llm/        — провайдеры (Gemini, Claude, Ollama)
tools/      — инструменты (поиск, заметки, файлы, планы)
ui/         — терминальный интерфейс
data/       — локальные данные (SQLite + ChromaDB)
```
